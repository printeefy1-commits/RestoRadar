# القرارات المعتمدة — 2026-10-22

مصدر الاعتماد: موافقة المالك في المحادثة على المعمارية والتوصيات، ثم إجاباته عن الأسئلة السابقة للبرمجة.

| البند             | القرار                                                                                                                  |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- |
| المعمارية         | خادم محلي صاحب السلطة التشغيلية، نسخة سحابية وأوامر بعيدة لا تُعتمد مستقلًا                                             |
| التقنيات          | React/TypeScript وFastify وPostgreSQL، وخدمة Python للرؤية لاحقًا                                                       |
| المنصة الأولى     | واجهة ويب للهاتف، هدف تجربة الهاتف الأول Android                                                                        |
| العتاد والكاميرات | لم يحدد المالك نظام الجهاز أو GPU أو طراز الكاميرات بعد؛ لا نفترض دعمها                                                 |
| مهلات المهام      | يدخل المالك الأربع قيم عند الإعداد دون قيم افتراضية؛ القبول من التعيين والإكمال من القبول                               |
| تحديث السياسة     | ينطبق على محاولات الإسناد الجديدة، لا يغير المهلات المحفوظة للمحاولات الحالية                                           |
| المهمة القديمة    | إلغاء مهمة الاستقبال غير المكتملة عند نهاية جلستها؛ إلغاء مهمة التنظيف غير المكتملة عند جلوس ضيوف جدد؛ حفظ السبب والسجل |
| الجاهزية          | إكمال النادل لا يعني الجاهزية؛ يظل التحذير إلى تأكيد المدير أو المالك                                                   |
| التنظيف           | تدفق بسيط دون Start Cleaning في v1                                                                                      |
| الجلسة اليدوية    | لا تنشئ تنبيه وصول تلقائيًا                                                                                             |
| تفعيل الخرائط     | تفعيل تدريجي بعد التحقق، وإعداد وتفعيل الخرائط للمالك فقط                                                               |
| AI                | لا اعتماد للأرقام التوضيحية للثقة قبل القياس الميداني                                                                   |
| الفيديو           | محلي افتراضيًا دون رفع مستمر أو حفظ خام افتراضي                                                                         |

تفاصيل التطبيق التأسيسي: لا يسمح بتأكيد جاهزية طاولة مشغولة. عند تأكيد المدير الجاهزية، تُلغى مهمة التنظيف المفتوحة بسبب `MANAGER_CONFIRMED_READY` دون ادعاء إكمالها. دورة التنظيف غير المحسومة لا تتكرر بسبب جلوس مجموعة أخرى؛ يمكن إعادة إسناد المهمة الملغاة بمحاولة جديدة بعد خلو الطاولة. المؤقت يبدأ عند تأكيد المغادرة ويبقى مشتقًا من وقت الدورة الأصلي.

المؤجل لاعتماد التشغيل الحقيقي: معايرة النموذج، سياسة الاحتفاظ بالبيانات وأدلة التشخيص، توافق الكاميرات والعتاد، مزود السحابة والدفع، والمراجعة المحلية للخصوصية. لا تحجب هذه البنود بناء الأساس والمحاكاة، لكنها تمنع ادعاء جاهزية الإنتاج.
