# تسليم MVP v1

| المرحلة                | الحالة            | المخرجات والتحقق                                                                                          |
| ---------------------- | ----------------- | --------------------------------------------------------------------------------------------------------- |
| A: المعمارية والسياسات | معتمدة            | قرارات المالك موثقة، عتاد الكاميرات ومعايرة النموذج مؤجلان                                                |
| B: الأساس المحلي       | منفذ أوليًا       | عقود، PostgreSQL، صلاحيات، جلسات، جاهزية، مهام، تنبيهات، تدقيق، منع تكرار واختبارات تعارض                 |
| C: الواجهات            | نسخة وظيفية أولية | واجهة عربية متجاوبة للأدوار الثلاثة مع أحداث محاكاة؛ اختبار متصفح لتدفق الاستقبال والتنظيف                |
| D: الفيديو والرؤية     | تجربة مسجل أولية  | خدمة Python اختيارية، معاينة للمالك ومناطق مقاعد وتقرير جلوس CPU؛ الكاميرات الحية والمغادرة ودمجها مؤجلة  |
| E: الهجين              | الأساس فقط        | Outbox محلي موجود؛ يلزم Cloud API، مصالحة وإجراءات بعيدة، WebSocket ودفع Android                          |
| F: تجربة المطعم        | لم يبدأ           | جهاز Android فعلي، فيديو مصرح به، قياسات CPU/GPU وعدد البثوث، دقة الرصد، انقطاع WAN واستعادة ونسخ احتياطي |

قبل وصف v1 بأنه مكتمل، يلزم إثبات سيناريوهات القبول الثلاثة عشر ببيانات واقعية وتوثيق حدود الدعم، واستكمال دعم PWA وحياة الحسابات وإدارة الأسرار والاحتفاظ والحفظ الاحتياطي. اختبار المتصفح المحاكى لا يُعد اختبار Android ميدانيًا.

الخطوة التالية: تشغيل [تجربة الفيديو المسجل](operations/recorded-video-trial.md) على EC2 ومراجعة المناطق والنتائج بوسم يدوي. نماذج YOLO11 Large وRTMPose-t وByteTrack اختيارات تجريبية؛ لا اعتماد للدقة أو توافق الكاميرات أو جاهزية تجارية قبل القياس وحسم شروط الأوزان. ما زال تحقق المغادرة 30 ثانية والرصد الحي ضمن المرحلة D.
